## C. Viewport review targets

The following are practical inspection targets, not official platform requirements:

- Desktop: 1440 × 900 CSS px; also check a narrower 1280 × 800 view.
- Tablet: 768 × 1024 CSS px; check portrait and landscape if convenient.
- Mobile: 390 × 844 CSS px; also check a compact 320 × 700 view.

Use browser zoom 100% for the primary pass. If zoom changes reveal layout defects, record the zoom and viewport with the evidence.

## D. Visual checklist

- Logo proportions and alignment; no accidental stretching.
- Clear space around symbol and wordmark; compare to the candidate guidance while recognizing its provisional status.
- Color consistency against the approved core palette and actual background.
- Font rendering and expected fallback behavior.
- Arabic connected-letter shaping, diacritics, and glyph presence.
- RTL/LTR ordering and mixed Arabic/English punctuation, labels, numerals, and contact details.
- Text wrapping, line length, and hierarchy.
- Clipping, overlap, and horizontal/vertical overflow.
- Responsive layout at the targets above.
- Component spacing, states, and visual consistency across specimens.
- Keyboard focus visibility where controls or links are present.
