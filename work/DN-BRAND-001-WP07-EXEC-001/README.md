# DigitalNawa Social Identity Candidate

**Status: PROVISIONAL — NOT APPROVED FOR PRODUCTION**

## Package contents
- `social-identity-system.css` — reusable styles importing WP-06 component styles and, transitively, WP-02 tokens and WP-03 typography.
- `social-media-specimen.html` — gallery of profile identity, five covers, nine feed patterns, seven carousel slides, seven story patterns, five thumbnails, and three pillar styles.
- `social-media-templates.html` — composed carousel, AI/automation post, development tutorial, project announcement, story sequence, and five video thumbnail examples.
- `social-format-registry.json` — nine provisional design presets.
- `social-template-index.json` — machine-readable index of generated examples.
- `social-identity-guidelines.md` — architecture, rules, limitations, and Final QA checklist.
- `SHA256SUMS.txt` — hashes of the other seven deliverables only.

## Open locally
Open either HTML file in a browser from this folder. Keep the folder beneath the project `work` directory and retain sibling WP-02, WP-03, WP-04, and WP-06 candidate packages for local CSS/SVG references.

## Dependencies and candidate status
No packages, fonts, scripts, or external network assets are required. CSS and logo references are local and relative. Font families are name-only provisional references. The canvas sizes and safe-area notes are design presets, not current platform specifications. All social templates and format presets are PROVISIONAL — NOT APPROVED FOR PRODUCTION.
